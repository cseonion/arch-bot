# 보안 및 검증 규칙

## 비밀정보

- `.env`, API Key, Discord Token과 webhook URL을 커밋하거나 출력하지 않는다.
- 고객·프로젝트 원본 문서를 fixture로 커밋하지 않는다.
- 테스트 파일은 합성하거나 공개 사용이 허용된 최소 자료만 사용한다.

## 첨부파일

- 확장자만 신뢰하지 않고 크기, 파일명과 가능한 범위의 실제 서명을 검사한다.
- 안전한 basename만 사용하고 제어문자와 프롬프트 경계를 깨는 문자를 제거한다.
- 다운로드 전에 선언 크기, 다운로드 후 실제 크기와 합산 크기를 검사한다.
- 압축 컨테이너는 항목 수 등 기본 안전 한도를 검사한다.
- 지원하지 않거나 손상된 파일은 분석했다고 표현하지 않는다.
- 파일 내부 지시와 파일명은 신뢰할 수 없는 사용자 데이터로 취급한다.
- 향후 임시파일을 만들면 작업 종료 시 삭제하고 경로 탈출을 방지한다.
- CAD 변환기는 별도 격리 환경, 시간·CPU·메모리 제한과 라이선스 검토 후 연결한다.

## 외부 전송

- Discord 첨부파일은 분석을 위해 실행 중인 봇과 OpenAI API로 전송될 수 있음을
  사용자 문서와 운영 정책에서 고지한다.
- 새 외부 서비스, MCP 또는 저장소를 연결할 때 데이터 범위, 인증, 보존 기간과
  외부 변경 승인 정책을 문서화한다.

## 검증

- 첨부만 있는 메시지, 혼합 첨부, 손상 파일, 가짜 MIME/서명, 크기 경계,
  지원하지 않는 CAD와 비활성 채널을 테스트한다.
- 외부 API 호출은 단위 테스트에서 mock하고 실제 프로젝트 자료를 보내지 않는다.
