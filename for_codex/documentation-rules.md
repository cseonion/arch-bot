# 문서 작성 규칙

## README.md

서비스 사용자를 위한 문서다. 최소한 다음 두 섹션을 유지한다.

1. `개요 및 소개`
2. `채널별 역할 및 기능 소개`

설치 명령, 내부 모듈 구조, 구현 세부는 최소화하고 `README_dev.md`로 연결한다.
사용자가 어떤 채널에서 무엇을 입력하고 어떤 결과와 한계를 기대할 수 있는지
쉽게 설명한다.

## README_dev.md

개발자를 위한 문서다. 최소한 다음 내용을 유지한다.

1. 환경 세팅 방법
2. 채널별 역할 및 기능에 따른 저장소 구조
3. 채널별 Tool/MCP/Skill 기본 설명

새 채널이나 파일 형식, Tool, MCP, Skill이 추가되면 관련 코드 위치, 설정,
실행 여부와 테스트 방법을 갱신한다.

## CHANGELOG와 Release 설명

반드시 한국어로 두 단을 작성한다.

1. 서비스 사용자가 이해하기 쉬운 기능 중심 설명
2. 개발자가 검토할 수 있는 구현·설정·마이그레이션·테스트 로그

내부 기술만 나열하지 않고 첫 단에서 실제 사용 경험의 변화를 먼저 설명한다.
